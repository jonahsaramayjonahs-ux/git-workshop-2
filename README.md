Reflection:
In your own words, what is the difference between git add and git commit?

At first I honestly thought git add and git commit basically did the same thing, but after trying them out I realized they're actually two different steps. The git add is like preparing your changes. It's telling Git "hey, these are the files I want to save in my next version." Nothing gets permanently recorded yet at this point, it's just kind of a "get ready" step. I found this helpful because it means I can pick exactly which files I want to include instead of saving everything all at once.

The git commit, on the other hand, is the actual saving part. After I've staged my files with git add, git commit locks those changes in for good as a new version, plus I get to add a short message saying what I changed. So every commit becomes like a snapshot of my project at that point in time, and I can go back and check it later using git log.

Basically, git add is like putting your things in a box, and git commit is like sealing that box and writing a label on it so you know what's inside.
